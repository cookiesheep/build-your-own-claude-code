### 公司背景（重要）

- 定价：$30/月（年付），Team $39/人/月

### 课程设计

**Stage 数**：6 个

| Stage | 名称 | 难度 | 预计时长 |
|-------|------|------|---------|
| 1 | Communicate with the LLM | Very Easy | < 5 min |
| 2 | Advertise the read tool | Easy | 5-10 min |
| 3 | Execute the read tool | Easy | 5-10 min |
| 4 | Implement the agent loop | Medium | 30min - 1h |
| 5 | Implement the write tool | Easy | 5-10 min |
| 6 | Implement the bash tool | Easy | 5-10 min |

**语言支持**：10 种（C, Go, Python, JS, TS, Rust, Zig, C++, C#, Java）

**课程描述**：
> "Claude Code is a terminal-based AI coding assistant that uses Large Language Models (LLMs) to understand code and complete programming tasks. In this challenge, you'll build your own Claude Code that is capable of editing files, running commands, and iterating until the task is done."

### 体验流程

1. 选择语言（Python/Java/...）+ 难度
2. 自动生成适配的代码仓库（git clone）
3. 安装 CodeCrafters CLI（`irm https://codecrafters.io/install.ps1 | iex`）
4. 本地写代码 → `codecrafters submit` → 本地跑测试 → 即时反馈
5. 回浏览器看结果，进下一个 stage

### 他们做得好的

1. **CLI 本地评测**：`codecrafters submit` 一键跑测试，体验丝滑
2. **多语言支持**：10 种语言，降低入门门槛
3. **难度自选**：初学者/有经验者适配不同代码仓库
4. **品牌信任**：顶级公司工程师背书
5. **评测基础设施**：这是他们平台的核心竞争力

### 他们的短板

1. **不是真实 Claude Code 源码** — 简化版 toy agent，每种语言独立实现
2. **没有 Web IDE** — 需要本地 clone + 配环境
3. **没有 TUI 反馈** — 纯文本 pass/fail，看不到 Agent "活过来"
4. **内容太浅** — 6 个 stage，1-2 小时完事，没有上下文压缩、子 Agent、规划
5. **还在 Beta** — 15% 完成度，可能改方向或砍掉
6. **仅英文** — 没有中文市场覆盖

## 四、BYOCC 当前状态（实事求是）

### 已建成

- Next.js 16 Web 平台（Monaco Editor + 文件树 + xterm.js 终端）
- Docker 容器管理（创建/注入/构建/清理）
- 后端 API（认证、容器、文件、进度）
- 文档站点（MkDocs，GitHub Pages）
- 部署（华为云 + byocc.cc + Cloudflare Tunnel）
- Lab 0 可用

### 未建成（核心教育内容）

- Lab 1-5 skeleton 代码 — 零
- 测试文件 — 零
- 参考实现 — 零
- 自动化评测（跑 vitest + 解析结果）— 后端只有 build（编译），没有 test（测试）

### 后端 submit 流程现状

```
POST /api/submit → injectFiles → node build.mjs --lab N → { success, buildLog }
```

只做 TypeScript 编译，不跑测试。距离 CodeCrafters 的 submit 体验，需要补：
1. Lab skeleton + 测试用例（前提）
2. 容器内加 `npx vitest run --reporter=json` 步骤
3. 解析测试结果，返回结构化数据
4. 前端展示面板

## 五、商业化分析

### 短期（6 个月内）：不建议收费

1. 教育内容不存在，没有可交付的价值
2. 竞品全部免费（learn-claude-code 51.2K star 免费）
3. CodeCrafters 能收 $30/月靠的是 11 门成熟课程 + YC 背书 + 企业客户
4. 订阅制需要持续内容更新，5 人学生团队能否持续？

### 中长期可行路径

**路径 A：开源核心 + 托管增值（推荐）**
- Lab 0-3 免费（GitHub）→ 吸引流量和 star
- 托管版（byocc.cc）收 API 额度费 / 高级 Lab 费
- 类似 GitLab 模式

**路径 B：B2B 教育授权**
- 授权给大学 AI/SE 课程，老师需要开箱即用的实验课
- 按班级/学期收费
- 与 YatSenOS 一脉相承

**路径 C：内容付费**
- 精编 Lab 教程 + 视频讲解
- 类似掘金小册 / 极客时间专栏
- 门槛低但天花板也低

## 六、下一步行动建议

### P0：写课本（2-3 周）

Lab 1-3 的 skeleton + 测试 + 参考实现，这是生命线。Lab 3 优先（80% 精力）。

### P1：补评测能力（1 周）

在 submit 流程加 test runner，CodeCrafters 最核心的体验就是 submit 即时反馈。

### P2：宣传（P0 完成后启动）

时机：Lab 0-3 skeleton 全部可用后。现在宣传 = 让人参观空教室。

渠道优先级：
1. GitHub trending
2. 知乎专栏（"我逆向了 41 万行 Claude Code 源码"）
3. V2EX / 掘金
4. B 站 demo 视频（TUI 从空到活的视觉冲击）

### P3：商业化试水（P0+P1 后）

先开源 Lab 0-3 积累用户，Lab 4-5 付费或走 B2B。

## 七、给老师的问题参考答案

**Q1: 可以模仿订阅制吗？**
短期不建议。先做免费内容验证用户需求，有用户后再考虑。

**Q2: 如何提升竞争优势？**
三个抓手：真实源码（已有）+ Web IDE 零配置（已有）+ 自动化评测（差一步）。组合是护城河。

**Q3: 宣传还是继续开发？**
先完成 Lab 1-3 skeleton 再宣传，2-3 周。否则流量变 bounce。

**Q4: 用户体验改进？**
最关键的改进：加"运行测试"按钮。但前提是先有 Lab 测试用例。
