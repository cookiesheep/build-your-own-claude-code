> 面向 AI agent 和团队成员：更新代码、检查服务、排查问题的完整操作指南。

## 一、更新代码并重启服务

每次本地 push 新代码后，在华为云上执行：

```bash
# 1. 拉取最新代码
cd /root/build-your-own-claude-code
git pull origin main

# 2. 重新安装依赖（仅当 package.json 有变化时需要）
cd /root/build-your-own-claude-code/server
npm install
cd /root/build-your-own-claude-code/platform
npm install

# 3. 重新构建前端（前端代码有变化时需要）
cd /root/build-your-own-claude-code/platform
npm run build

# 4. 重新构建服务端 generated 文件（lab-files.json 有变化时需要）
cd /root/build-your-own-claude-code/server
node scripts/generate-lab-config.mjs

# 5. 重启所有服务
systemctl restart byocc-server byocc-platform
```

## 二、systemd 服务管理

三个服务均为 systemd 管理，开机自启，崩溃自动重启。

```bash
# 查看所有服务状态
systemctl status byocc-server byocc-platform cloudflared

# 单独重启某个服务
systemctl restart byocc-server    # 后端 (Express, 端口 3001)
systemctl restart byocc-platform  # 前端 (Next.js, 端口 3000)
systemctl restart cloudflared     # Cloudflare Tunnel

# 停止/启动
systemctl stop byocc-server
systemctl start byocc-server

# 查看是否开机自启
systemctl is-enabled byocc-server byocc-platform cloudflared
```

## 三、查看日志

```bash
# 查看后端实时日志（最常用）
journalctl -u byocc-server -f

# 查看前端实时日志
journalctl -u byocc-platform -f

# 查看 Cloudflare Tunnel 日志
journalctl -u cloudflared -f

# 查看最近 100 行后端日志
journalctl -u byocc-server -n 100

# 查看今天的后端错误
journalctl -u byocc-server --since today -p err

# 查看某个时间段的日志
journalctl -u byocc-server --since "2026-04-27 10:00" --until "2026-04-27 12:00"
```

## 四、端口与进程排查

```bash
# 检查端口是否在监听
ss -tlnp | grep -E '3000|3001'

# 如果端口被占用（旧进程未退出）
fuser -k 3000/tcp
fuser -k 3001/tcp
systemctl restart byocc-server byocc-platform

# 查找残留的 node 进程
ps aux | grep node
```

## 五、数据库操作

SQLite 数据库位于 `/root/build-your-own-claude-code/server/byocc.sqlite`。

```bash
# 进入数据库命令行
cd /root/build-your-own-claude-code/server
node -e "
const Database = require('better-sqlite3');
const db = new Database('byocc.sqlite');
const tables = db.prepare(\"SELECT name FROM sqlite_master WHERE type='table'\").all();
console.log('Tables:', tables.map(t => t.name));
db.close();
"

# 清除某个 Lab 的已保存 workspace（调试用）
node -e "
const Database = require('better-sqlite3');
const db = new Database('byocc.sqlite');
const result = db.prepare('DELETE FROM code_snapshots WHERE lab_number = 0').run();
console.log('Deleted:', result.changes, 'rows');
db.close();
"

# 查看所有 workspace 快照
node -e "
const Database = require('better-sqlite3');
const db = new Database('byocc.sqlite');
const rows = db.prepare('SELECT user_id, lab_number, length(code) as size, updated_at FROM code_snapshots ORDER BY lab_number').all();
rows.forEach(r => console.log('Lab ' + r.lab_number + ' | user=' + r.user_id.substring(0,8) + '... | ' + (r.size/1024).toFixed(1) + 'KB | ' + r.updated_at));
db.close();
"
```

## 六、Docker 容器管理

```bash
# 查看所有 BYOCC 容器
docker ps -a --filter label=byocc.managed=true

# 查看某个容器的日志
docker logs <container_id> --tail 50

# 强制清理所有 BYOCC 容器（调试用）
docker ps -a --filter label=byocc.managed=true -q | xargs -r docker rm -f
```

## 七、Docker 镜像更新

当 sister 仓库（claude-code-diy）的 lab 文件有更新时，需要重新构建镜像。

```bash
# 1. 更新 sister 仓库
cd /root/claude-code-diy  # 或实际路径
git pull origin main

# 2. 重新构建镜像
cd /root/build-your-own-claude-code
./infrastructure/build-lab-image.sh /root/claude-code-diy byocc-lab

# 3. 清理旧容器（新镜像不会影响已运行的容器）
docker ps -a --filter label=byocc.managed=true -q | xargs -r docker rm -f

# 4. 验证镜像
docker images byocc-lab
```

## 八、环境变量

后端 `.env` 文件位于 `/root/build-your-own-claude-code/server/.env`。

关键配置项：

| 变量 | 说明 | 华为云上的值 |
|------|------|------------|
| `HOST` | 监听地址 | `0.0.0.0`（不是 127.0.0.1） |
| `PORT` | 后端端口 | `3001` |
| `CORS_ORIGINS` | 允许的前端来源 | 包含公网 IP 和域名 |
| `DEFAULT_API_KEY` | 默认 LLM API Key | 平台共享 key |
| `DEFAULT_API_BASE_URL` | LLM API 地址 | Anthropic 或代理地址 |
| `BYOCC_LLM_PROXY_URL` | 容器内 LLM 代理地址 | `http://host.docker.internal:3001/api/llm` |

修改 `.env` 后需要重启后端：
```bash
systemctl restart byocc-server
```

## 九、网络架构

```
用户浏览器
    ↓ Cloudflare Tunnel（byocc-tunnel）
    ↓
华为云服务器 :3000 (Next.js 前端)
    ↓ API 代理 /api/* → 127.0.0.1:3001
    ↓
华为云服务器 :3001 (Express 后端)
    ↓ Docker API
    ↓
Docker 容器 (byocc-lab 镜像)
    ├── ttyd :7681 (终端服务)
    └── /workspace/ (claude-code-diy 源码)
```

## 十、常见问题

### 前端访问不了

1. 检查前端服务：`systemctl status byocc-platform`
2. 检查端口：`ss -tlnp | grep 3000`
3. 检查日志：`journalctl -u byocc-platform -n 50`

### API 返回 521 或 "非法阻断"

这是 ICP 备案问题。华为云会拦截直接解析到服务器 IP 的域名。
**解决**：使用 Cloudflare Tunnel（已配置），不要用 A 记录直接指向服务器 IP。

### 容器启动失败 / esbuild 崩溃

容器内存不足会导致 esbuild 崩溃。当前已设置为 2GB 内存限制。
检查 `container-manager.ts` 中的 `CONTAINER_MEMORY_LIMIT`。

### Next.js 构建报错 tailwindcss / workspace root

清除 `.next` 缓存：
```bash
rm -rf /root/build-your-own-claude-code/platform/.next
cd /root/build-your-own-claude-code/platform
npm run build
systemctl restart byocc-platform
```

### npm install 失败（网络问题）

```bash
# 使用国内镜像
npm config set registry https://registry.npmmirror.com
npm install
```
